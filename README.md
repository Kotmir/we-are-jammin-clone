# 🕺 We Are Jammin (`we-are-jammin.xyz`) — Локальная копия

Автономная локальная версия популярного интерактивного сайта-пранка (мема) `we-are-jammin.xyz`.

## 📖 О проекте

При открытии страница встречает посетителя предупреждением о том, что видео-опыт «персонализирован», и просит не демонстрировать экран посторонним:
> *"The video experience you're about to see is personalized. Please do not share your screen with anyone while watching. Thank you."*

После нажатия кнопки запуска на экране начинает воспроизводиться динамичный видеоряд из мультфильма **«Капитан Подштанник» (Captain Underpants)** под главную музыкальную тему из игры **Jetpack Joyride**. В такт музыке поверх видео начинают поочередно выводиться реальные технические данные об устройстве пользователя, его браузере, видеокарте и IP-адресе, создавая комичный эффект «взлома» или «деанонимизации».

## 🚀 Инструкция по запуску

### ⚠️ Почему нельзя просто открыть `index.html` двойным кликом?
Сайт загружает видео не напрямую через тег `<video src="...">`, а асинхронно через JavaScript-функцию `fetch('jammin.mp4')`. Из соображений безопасности современные браузеры (Chrome, Edge, Firefox) блокируют `fetch`-запросы при открытии файлов напрямую с жесткого диска по протоколу `file:///`, выдавая ошибку **`TypeError: Failed to fetch`**.

Для корректной работы сайт необходимо запускать через локальный веб-сервер.

---

### Способ 1: Автоматический запуск в один клик (Рекомендуется)

Вы можете создать ярлык для запуска сервера, чтобы не вводить команды вручную:

1. В папке с файлами (`we-are-jammin`) создайте обычный текстовый документ и переименуйте его в **`start.bat`** (убедитесь, что расширение изменилось с `.txt` на `.bat`).
2. Кликните по нему правой кнопкой мыши → **Изменить** (открыть в Блокноте) и вставьте следующие строки:
   ```bat
   @echo off
   title We Are Jammin Local Server
   cd /d "%~dp0"
   echo Starting local web server on http://localhost:8000 ...
   start http://localhost:8000
   python -m http.server 8000
   ```
3. Сохраните файл. Теперь при двойном клике по `start.bat` сервер запустится сам и автоматически откроет рабочую страницу в браузере.

---

### Способ 2: Ручной запуск через командную строку (Python)

Если у вас установлен Python (версии 3.x):

1. Откройте командную строку (`Win + R` → введите `cmd` → нажмите `Enter`).
2. Перейдите в папку с сайтом:
   ```cmd
   cd /d C:\Users\KotMir_You\site\we-are-jammin
   ```
3. Запустите встроенный веб-сервер на порту `8000`:
   ```cmd
   python -m http.server 8000
   ```
4. Откройте браузер и перейдите по адресу:
   **[http://localhost:8000](http://localhost:8000)**
5. Для остановки сервера вернитесь в окно командной строки и нажмите сочетание клавиш `Ctrl + C`.

---

### Способ 3: Запуск одной командой (создание `start.bat` через консоль)

Если вы уже находитесь в папке `we-are-jammin` в командной строке, просто выполните эту команду, и файл `start.bat` создастся автоматически:
```cmd
(echo @echo off & echo cd /d "%~dp0" & echo start http://localhost:8000 & echo python -m http.server 8000) > start.bat
```

## ⚙️ Как устроен сайт (Технический разбор)

Вся логика страницы находится внутри файла `index.html` и выполняется в браузере клиента (Client-Side):

1. **Предварительная буферизация видео (`Blob` и `ReadableStream`):**
   При загрузке страницы (`window.onload`) скрипт скачивает файл `jammin.mp4` через `fetch()`, читает поток данных через `response.body.getReader()`, собирает чанки в единый объект `new Blob(chunks, { type: 'video/mp4' })` и создает временную внутреннюю ссылку `URL.createObjectURL(blob)`. Это гарантирует, что когда пользователь нажмет кнопку старта, видео не будет подтормаживать, а тайминги появления текста идеально совпадут с битом музыки.

2. **Сбор данных об устройстве (Browser Fingerprinting):**
   Скрипт не взламывает систему, а использует открытые штатные API любого веб-браузера:
   * **Система и браузер:** `navigator.userAgent`, `navigator.platform`, `navigator.languages`.
   * **Параметры дисплея:** `window.screen.width / height` (разрешение экрана), `window.innerWidth / innerHeight` (размер окна браузера), `screen.pixelDepth` (глубина цвета).
   * **Процессор и память:** `navigator.hardwareConcurrency` (количество потоков процессора) и `navigator.deviceMemory` (доступная оперативная память браузера).
   * **Видеокарта (GPU):** Создается скрытый элемент `<canvas>` с контекстом `WebGL`, после чего через расширение `WEBGL_debug_renderer_info` считывается точное название видеочипа и графического драйвера (например, `NVIDIA GeForce RTX 4060 Direct3D11`).

3. **Получение сетевых данных (IP и Геолокация):**
   Для отображения IP-адреса и местоположения скрипт обращается к публичным API геолокации.

## 🔍 Разница между локальной копией и оригинальным сайтом

При сравнении вывода локальной версии (`http://localhost:8000`) и оригинала (`https://we-are-jammin.xyz/`) можно заметить небольшие отличия в списке параметров:

| Категория данных | Локальная копия (`localhost`) | Оригинальный сайт | Почему есть разница? |
| :--- | :--- | :--- | :--- |
| **Базовый IP и локация** (`IP Address`, `Full Location`) | ✅ Отображается | ✅ Отображается | Запрашивается напрямую из браузера через открытый API. |
| **Детальная география** (`Country`, `Region`, `ZIP Code`, `Latitude`, `Longitude`, `Timezone`) | ❌ Скрыто | ✅ Отображается | Расширенный GeoIP-сервис проверяет домен отправителя (`Origin`). Запросы с `localhost` отклоняются сервером API, поэтому скрипт пропускает пустые поля. |
| **Данные провайдера** (`ISP`, `Organization`, `Autonomous System`) | ❌ Скрыто | ✅ Отображается | Аналогично: данные об ASN/провайдере отдаются только при запросе с домена `we-are-jammin.xyz`. |
| **Разрешение экрана** (`Screen / Window Width & Height`) | Зависит от окна (напр. `1920x1080`) | Зависит от окна (напр. `2560x1440`) | Скрипт считывает текущие размеры того монитора и окна, где открыта вкладка, с учетом масштабирования Windows (100%, 125%, 150%). |
| **Железо ПК** (`CPU`, `RAM`, `GPU`, `OS`, `Browser`) | ✅ Полное совпадение | ✅ Полное совпадение | Считывается локально из самого браузера и не зависит от сервера. |

## 🛡️ Безопасность и конфиденциальность

* **Безопасно ли запускать сайт?** Да, полностью. Скрипт лишь выводит на ваш собственный экран информацию, которую любой веб-сайт и так видит при каждом вашем заходе в интернет.
* **Передаются ли данные куда-то в локальной версии?** Нет. Скрипт аналитики `js/script.js` при обнаружении адреса `localhost` автоматически блокирует отправку любых событий (в консоли появляется уведомление `Ignoring Event: localhost`)."# we-are-jammin-clone"
